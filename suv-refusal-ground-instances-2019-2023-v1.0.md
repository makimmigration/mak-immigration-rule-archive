# IRCC Start-Up Visa Refusal-Ground Instances, January 2019–March 2023

Version: 1.0  
Published: 2026-09-16  
Publisher: MAK Canadian Immigration Services · Immigration Data Observatory  
Evidence basis: IRCC completed ATI request `A-2025-56513` plus current first-party legal/program sources  

## Purpose

This is a bounded historical data reference derived from IRCC completed Access to Information request `A-2025-56513` and its publicly available released copy. It preserves IRCC's source-system labels rather than converting ambiguous codes into modern legal conclusions.

It is **not** a current Start-Up Visa refusal-rate report, does **not** count unique refused applications, and does **not** predict an applicant's outcome.

## Source and coverage

Official completed-ATI record:  
https://search.open.canada.ca/ati/record/cic,2025,8,A-2025-56513

Public released copy:  
https://theijf.org/open-by-default/28270168

The released table is titled **Top 10* Refusal Grounds for Permanent Resident Start-Up Visa Applications Refused from January 01, 2019 to March 31, 2023 by Country of Residence (in Instances*)**.

The released data cover January 1, 2019 to March 31, 2023 and were extracted from COGNOS (MBR) on April 26, 2023. The underlying request asked for broader 2018–2025 material, so this reference does not imply the release answered the full request.

The source footnote states that one application may be refused for more than one refusal ground. All numbers below are therefore **refusal-ground instances**, not unique applications.

## Current-program boundary

As of September 16, 2026, IRCC states that the Start-Up Visa Program is paused, new permanent-residence applications are not currently accepted, applicants with a valid 2025 commitment certificate had to apply by June 30, 2026, and IRCC continues processing applications accepted before that date.

Current IRCC source:  
https://www.canada.ca/en/immigration-refugees-citizenship/services/immigrate-canada/start-visa/about.html

This historical reference is therefore useful for research into past decision patterns and pending inventory, not as a current intake guide.

## Citation and interpretation rules

Use the exact request number `A-2025-56513`, the January 2019–March 2023 coverage, the April 26, 2023 extraction date, and the term **refusal-ground instances** whenever citing the figures.

Do not state or imply that:

- 223 unique applications were refused;
- the table contains every refusal ground;
- the release covers the full 2018–2025 period requested;
- the historical distribution is a 2026 refusal distribution;
- `R98(1)` is current R98.01(1) or R98.10(1);
- `A89` has a verified substantive meaning from this release; or
- frequency is an approval/refusal probability.
