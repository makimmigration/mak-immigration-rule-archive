Methods & provenance

How the public IRCC Start-Up Visa refusal-ground dataset was transcribed, bounded, validated and version-controlled.

← Dataset reference · CSV · Researcher kit

Companion to: IRCC Start-Up Visa Refusal-Ground Instances, January 2019–March 2023, version 1.0, published September 16, 2026. This page documents reproducibility controls; it does not add new IRCC data or reinterpret unresolved source-system labels.

1. Primary source chain

  1. Official request identity: IRCC completed ATI request A-2025-56513, recorded in the Government of Canada completed-request catalogue: official ATI record.
  2. Public released copy: the released package is publicly accessible through the Investigative Journalism Foundation's Open by Default repository: released copy.
  3. Source table: Top 10* Refusal Grounds for Permanent Resident Start-Up Visa Applications Refused from January 01, 2019 to March 31, 2023 by Country of Residence (in Instances*).
  4. Source extraction date: the released material states that the data were extracted from COGNOS (MBR) on April 26, 2023.
  5. Coverage used here: January 1, 2019 through March 31, 2023. The broader wording of the underlying ATI request is not treated as evidence that the released table covers 2018–2025.

2. Transformation protocol

  1. Transcribe each refusal-ground row and each year value from the released table without renaming the IRCC source label.
  2. Preserve R98(1) and A89 exactly as released. No modern legal meaning is inferred for either unresolved label.
  3. Store 2023 as 2023_to_mar31 so a downstream user cannot reasonably mistake the column for a full calendar year.
  4. Recompute every row total from the five displayed year cells.
  5. Recompute every annual total from the refusal-ground rows.
  6. Recompute the grand total in both directions: sum of row totals and sum of annual totals.
  7. Add legal/historical cross-references only in separate metadata fields. Cross-references never replace the source label or alter the numeric cells.
  8. Add a terminal TOTAL_INSTANCES row to the CSV as a validation row, not as an additional refusal ground.

6. Version discipline

  • A change to a numeric source value, coverage period, source label, or interpretation of the unit of count requires an explicit correction/version event rather than a silent overwrite.
  • Ancillary citation-format or discoverability improvements may be added without changing the underlying v1.0 numeric dataset, provided they do not alter its evidence claims.
  • If a first-party IRCC codebook or other primary evidence later resolves R98(1) or A89, the resolution must identify the new source and must not be back-filled silently into the historical v1.0 evidence record.

7. Reproduction checklist

  1. Open the public released ATI copy and locate the exact source table named above.
  2. Compare all ten refusal-ground labels and five displayed year columns against the CSV.
  3. Recalculate each row total.
  4. Recalculate annual totals: 63, 27, 34, 38 and 61.
  5. Confirm both arithmetic routes produce 223.
  6. Confirm 2023 is treated as partial-year through March 31.
  7. Confirm no analysis converts 223 instances into a unique-application count or a refusal rate.
  8. For legal meaning, use current primary legal sources and the controlled cross-reference status in the canonical reference; do not infer meanings for unresolved source labels.
Research boundary: this reproducibility companion describes how MAK converted a public historical IRCC table into a bounded research dataset. It does not establish current Start-Up Visa intake rules, current refusal patterns, causation, or an applicant's likelihood of success.

Current legislation, regulations and official IRCC program guidance control for live matters. The official ATI request number and the public released copy remain the evidentiary anchors for the historical figures.
