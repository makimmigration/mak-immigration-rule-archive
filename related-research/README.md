# MAK related research datasets

This directory is the citation and reuse gateway for three MAK Canadian Immigration Services research datasets that sit alongside the Canadian Immigration Rule Change Archive.

- **R01 — 2027 Express Entry Reform Evidence Tracker**  
  Canonical: https://makimmigration.ca/express-entry-2027-reform-tracker/  
  Version DOI: https://doi.org/10.5281/zenodo.23118253

- **R02 — IRCC ATIP Intelligence Index**  
  Canonical: https://makimmigration.ca/ircc-atip-intelligence-index/  
  Version DOI: https://doi.org/10.5281/zenodo.23119138

- **R03 — Express Entry Invited Candidates Data Observatory**  
  Canonical: https://makimmigration.ca/express-entry-invited-candidates-program-province/  
  Version DOI: https://doi.org/10.5281/zenodo.23119703

All three MAK-authored research objects are recorded as **CC BY 4.0** on their corresponding Zenodo deposits.

The underlying Government of Canada sources remain controlling for Canadian immigration law, policy, official data and released government records. An external repository record or MAK publication is a distribution mechanism, not an independent endorsement.

Files:
- `index.html` — human-readable research directory
- `catalogue.json` — machine-readable metadata
- `citations.bib` — BibTeX citations
- `citations.ris` — RIS citations
