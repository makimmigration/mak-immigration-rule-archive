Event data dictionary

Field-level meaning for the canonical events.json release and the flat CSV export.

← Archive home · Researcher kit · JSON schema

FieldMeaning
idStable archive event identifier.
jurisdictionJurisdiction to which the event applies, such as Canada or a named province.
authorityOfficial public authority responsible for the controlling source.
topic_keyStable machine-oriented topic key used to group related historical events.
topicHuman-readable topic title.
change_typeCompact classification of the kind of rule or policy change recorded.
announcement_dateDate an official announcement or notice was published, if known. This is not automatically the effective date.
rule_observed_fromEarliest date on which the archive verified the stated rule from the cited official evidence.
effective_fromLegal or program effective date only where an official source explicitly supports it or the controlling instrument establishes it. May be null.
effective_toSupported end date for that rule state. Null where no defensible record-level end date is established.
date_basisExplanation of why the archive uses the recorded date treatment.
statusArchive status label describing whether the event is current, temporary, superseded or otherwise bounded.
previous_ruleHistorical predecessor context or an explicit statement that earlier coverage is incomplete.
new_ruleMAK-authored summary of the rule or policy state supported by the controlling source.
transition_ruleTransition, grandfathering, exception or historical-bounding information relevant to the change.
supersedes_event_idOlder archive event replaced by this event where the relationship is fully supported.
superseded_by_event_idNewer archive event that replaced this event where the relationship is fully supported.
controlling_source_urlOfficial source used as the controlling evidence for the archived proposition.
supporting_source_urlsAdditional official sources that support the same event or its transition chain.
evidence_statusEvidence-control label. Current v0.8.0 release uses official-source verification for published events.
last_verified_atDate the event's official-source evidence was last verified for the release.

Interpretation: a missing event does not prove that no rule existed. It means this release does not contain enough verified historical evidence to answer that topic/date safely. See methodology.
